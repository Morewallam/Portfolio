Emotion Defender

This is a small tower defence game that is played by making difference facial expressions to defeat enemies. The game is built using Pygame for the graphics and game logic. It uses a machine learning model that we trained to identfity the players face and their expression. Causing them to defeat the enemies corresponding to that emotion.

Plane Segmentation

This is a plane indentifer and segmentation model, that given an overhead image of an airport it can indetify the airplanes in the image, then segment each airplane. It was built using pytorch with a combination of the pre-trained model Detectron2 and customs layers and connections to allow the model to work for this scenario.
